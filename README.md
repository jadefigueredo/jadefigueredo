# Jade Figueredo

Software Engineer at [Jusbrasil](https://www.jusbrasil.com.br), working on **data collection**: the crawlers and pipelines that bring legal content (case law, legislation and *súmulas*) from Brazilian courts and official sources into the product, and the tooling that keeps them reliable.

## What I work on

- **Crawler platform.** Features and fixes in the engine that runs our crawlers: PDF → HTML conversion through cloud storage for sources protected by cookies and captchas, reCAPTCHA handling, scheduling changes to avoid blocks, and security hardening of headless-browser sidecars.
- **Reliability and observability.** Success-rate SLOs with Prometheus and Sloth, recalibrated from measured baselines; Grafana dashboards for crawler health; metrics fixes so the error budget tells the truth; runbooks for on-call.
- **Automation and LLM agents.** A Slack bot that posts the daily crawler health to the on-call channel straight from Grafana, alert triage automation, and skills and docs that help AI agents write crawler specs.
- **Pipelines and deploy.** Python services on Kubernetes with Helm and KEDA autoscaling, Docker builds, CI fixes and migrations between deploy systems.
